### 2. Veredicto de Desarrollo (StockScanner)

**Prioridades de hoy, por orden:**

1. **Fix del hallazgo #33 (Alta, prioridad máxima).** El parseo `int(fila.get(k) or 0)` de la serie de recomendaciones de analistas revienta con cualquier `NaN` en una categoría mensual, apagando todo el bloque de analistas y filtrando un mensaje de error de Python crudo a la interfaz. Instrucción concreta para `datos_yfinance.py:443` y el patrón análogo en `datos_finnhub.py:250`:
```python
def _entero_seguro(v) -> int:
    try:
        f = float(v)
    except (TypeError, ValueError):
        return 0
    return int(f) if f == f else 0   # f == f es False solo para NaN
```
   y sustituir `int(fila.get(k) or 0)` por `_entero_seguro(fila.get(k))` en ambos puntos. Este bug es especialmente urgente porque las últimas tres sesiones han ampliado la búsqueda a tickers internacionales de menor cobertura de analistas, precisamente donde Yahoo Finance es más propenso a dejar huecos en la serie mensual.

2. **Separar mensaje de usuario y detalle técnico en errores de datos de mercado (prioridad alta).** Las 7 funciones `obtener_*` de `datos_finnhub.py`/`datos_yfinance.py` con el patrón `except Exception as e: return Dato(None, str(e)...)` deben distinguir `_SinDatos` (mensaje pensado para el usuario, se muestra tal cual) de cualquier otra excepción (mensaje genérico fijo + log del detalle técnico). Esto cierra la puerta a que cualquier fallo inesperado —no solo el #33— termine como texto de implementación interna visible en la tarjeta de análisis.

3. **Pseudocódigo de diseño para el punto único de responsabilidad (prioridad media, estructural).** Introducir en un módulo común (p. ej. `datos_comun.py`) un wrapper:
```python
def dato_seguro(fn, motivo_generico: str):
    def envuelto(*args, **kwargs):
        try:
            return fn(*args, **kwargs)
        except _SinDatos as e:
            return Dato(None, str(e), _ahora())
        except Exception as e:
            logging.exception("Error inesperado en %s", fn.__name__)
            return Dato(None, motivo_generico, _ahora())
    return envuelto
```
   aplicado a las funciones públicas `obtener_*`. Mismo antipatrón de fondo que el hallazgo #6 (fallos silenciosos sin loguear en `db_supabase.py`), ahora confirmado también en la capa de datos de mercado — justifica tratarlo como una sola iniciativa de arquitectura, no dos parches independientes.

**Prioridad media (para sesiones futuras, no bloqueante hoy):** suite de tests unitarios para los motores `core_*.py` (hallazgo #9, reforzado por el patrón de los hallazgos #26-#33, todos encontrados por ejecución manual); las mejoras de prioridad media ya conocidas de sesiones anteriores (panel de fiabilidad de datos, racha de sorpresas de earnings, re-chequeo automático de exclusiones, ficha de candidata autogenerada) siguen abiertas sin cambios. Sigue abierto y sin bloquear hoy el hallazgo #6 (logging de excepciones en `db_supabase.py`) y #7/#10/#20 (limitaciones de divisa y sufijos bursátiles internacionales), ambos con relevancia directa si el comité selecciona pronto una de las candidatas internacionales investigadas hoy.
