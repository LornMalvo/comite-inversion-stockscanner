**Prioridad 2 (severidad media, corrección de caso límite):** hallazgo #24 — en `core_indicadores.rsi()`, forzar `RSI = 100` cuando `perdida` es 0 y `ganancia > 0` (racha alcista pura), en vez de dejar que la división produzca `NaN`:

```python
def rsi(df, periodo=14):
    ganancia, perdida = ...  # cálculo existente
    rs = ganancia / perdida.replace(0, np.nan)
    valor = 100 - 100 / (1 + rs)
    # caso límite: sin pérdidas y con ganancia real -> sobrecompra máxima, no "sin dato"
    valor = valor.where(~((perdida == 0) & (ganancia > 0)), 100.0)
    # caso límite simétrico: sin ganancia ni pérdida -> neutral, no "sin dato"
    valor = valor.where(~((perdida == 0) & (ganancia == 0)), 50.0)
    return valor
```

Esto es especialmente relevante para el propio mandato del comité: un RSI que desaparece justo en el escenario de mayor sobrecompra podría ocultar información de Timing en una futura candidata de momentum fuerte (como CRM hoy, aunque no llegó a disparar el caso límite).
